## 1. VISION & IDENTITY
**Nihomi (にほみ)** is not a conventional Japanese language school website or a static textbook portal.
Nihomi is the **Japan Companion**:
> *"You learn Japanese. Nihomi coordinates everything else."*

The learner journey is designed with a single uncompromising objective:
> **ZERO JAPANESE → JAPAN READY**

The learner should never look at a 50-item checklist or feel lost in curriculum admin dashboards. Instead, at every waking session, the interface unequivocally answers:
> **"What is my Next Best Mission right now?"**

## 2. THE 10-PHASE LEARNER PROGRESSION LATTICE

```
[ PHASE 0: ARRIVAL ]
Visitor lands → Understands "Learn by speaking, ready for Tokyo in 60-90 days" → 1-Click "বিনামূল্যে শুরু করি"

[ PHASE 1: FIRST 3 MINUTES — THE FIRST AHA ]
Pure Single Character 'あ' (a)
• Hear crisp Tokyo pronunciation
• Observe 3 authentic MEXT stroke directions
• Tactile trace on Japanese Hosho paper canvas
• Immediate positive reinforcement (+10 XP)
• ZERO UNTAUGHT KANA (Strict prohibition against displaying 'あい' or 'あさ')

[ PHASE 2: FIRST COMBINATION UNLOCK ]
Character 'い' (i)
• Hear & Trace 'い'
• Milestone Discovery: 'あ' + 'い' = 'あい' (Ai • ভালোবাসা / Love)
• Emotional Resonance: "I can synthesize real Japanese words!"

[ PHASE 3: 5-VOWEL MASTERY GATE ]
Progress through 'う' (unlocks 'いう'), 'え' (unlocks 'いえ', 'うえ'), 'お' (unlocks 'あお', 'おおい')
• 5-Vowel Review Quiz Gate: Must pass 5 rapid-fire questions testing strictly { あ, い, う, え, お }
• Celebration confetti + +50 XP + Progression unlock to 'か' series

[ PHASE 4: READING SKILL TREE ]
Character Recognition → Sound Recognition → Pair Reading → Controlled Word Reading → Phrase Rhythm
• Progressive introduction of Dakuten, Handakuten, Yoon (きゃ, しゅ, ちょ), and Small っ (Sokuon)

[ PHASE 5: VOCABULARY OS GROWTH THROUGH USE ]
Words are unlocked strictly through acquired phonetic units:
• Character Learned → Controlled Word Unlocked → Contextual Meaning → Audio Recall → Real Use

[ PHASE 6: KANJI OS (ATTACHMENT TO MEANING) ]
Kanji is introduced as visual anchors for mastered vocabulary, never as disconnected abstract stroke puzzles.

[ PHASE 7: GRAMMAR OS (COMMUNICATION PATTERNS) ]
Pattern Introduction → Meaning in Bengali → Controlled Example → Construction Drill → Real Life Use

[ PHASE 8: TOKYO REALITY MISSIONS (WORKOS) ]
Simulated real-world Tokyo situations:
• Tokyo 7-Eleven Konbini: Purchasing onigiri & hearing "Arigatou gozaimasu"
• Shinjuku Station: Asking for Yamanote Line platform
• Ramen Vending Machine: Reading tickets & ordering noodle firmness
• Baito Interview: Answering shifts, greeting the tenchou (store manager)

[ PHASE 9: AUTHENTICATION & VALUE RETENTION ]
Soft conversion point: After achieving the First Aha and Word Unlock:
• "তোমার আজকের progress save করে রাখবো?"
• 1-Tap Google / Email instant persistence

[ PHASE 10: JAPAN READINESS & PRO UPGRADE ]
Comprehensive JIS Rirekisho & Shokumu Keirekisho CV Studio, 180-mark Simulated Mock Exams, 24/7 AI Coach.
```

## 3. MASTER PEDAGOGICAL AXIOMS

1. **The Strict Cumulative Unlock Law:**
   A learner must NEVER see an untaught Japanese character, sound-symbol combination, or structural unit inside learner-facing content unless the prerequisite has been explicitly unlocked.
2. **Error as Diagnostic Coaching:**
   Mistakes are never failures or shaming events. The engine classifies errors into visual, phonetic, or recall confusion, and responds with warm, supportive Bengali micro-guidance followed by a simplified retry.
3. **No Decorative Cognitive Overhead:**
   Every element on the Zen Learning Canvas serves active cognitive acquisition: listening, stroke observation, tactile production, and meaningful synthesis.
