## ২. ব্যাকএন্ড কুয়েরি ও সার্ভিস রোল আচরণ (service_role Query Compatibility)
* ব্যাকএন্ড নোড.জেএস সার্ভার (`server/prisma.ts`) ডিবি সংযোগের ক্ষেত্রে সরাসরি PostgreSQL কানেকশন স্ট্রিং ব্যবহার করে যা সার্ভিস-লেভেল ক্রেডেনশিয়াল বহন করে।
* PostgreSQL-এ টেবিল ওনার অথবা সুপারইউজার/সার্ভিস-রোলের জন্য RLS স্বয়ংক্রিয়ভাবে বাইপাস হয় (যদি না `FORCE ROW LEVEL SECURITY` দেওয়া হয়)।
* ফলে ব্যাকএন্ড সার্ভিসের এআই জব, পেমেন্ট আইপিএন ভ্যালিডেশন, এবং ফাউন্ডার সামারি এপিআই-তে কোনো কোয়েরি ফেইলিউর ঘটবে না।
