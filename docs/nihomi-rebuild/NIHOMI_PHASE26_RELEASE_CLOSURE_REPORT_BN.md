## ৬. ৪টি সৎ প্রোডাকশন ব্লকার (The 4 Honest Production Blockers)

প্রোডাকশন সততা বজায় রাখতে নিম্নোক্ত ৪টি পয়েন্টে কোনো মিথ্যা "রেডি" দাবি করা হয়নি:

1. **BLOCK-01: Supabase Live RLS সিকিউরিটি মাইগ্রেশন:**
   - ২৭টি টেবিলের আরএলএস হার্ডেনিং মাইগ্রেশন ফাইল (`prisma/migrations/20261016_supabase_rls_security_hardening.sql`) প্রস্তুত।
   - কিন্তু লাইভ ডাটাবেসে এটি প্রয়োগ করতে ফাউন্ডারের আনুষ্ঠানিক অনুমোদন ও রিমোট ডাটাবেস ব্যাকআপ প্রয়োজন। বর্তমানে লোকাল রেজিলিয়েন্ট স্টেটে নিরাপদ রাখা হয়েছে।

2. **BLOCK-02: বিকাশ / এসএসএলকমার্জ (bKash / SSLCommerz) লাইভ গেটওয়ে:**
   - স্যান্ডবক্স আর্কিটেকচার ও সিগনেচার ভেরিফিকেশন প্রস্তুত।
   - তবে লাইভ প্রোডাকশন মার্চেন্ট কী, অ্যাপ সিক্রেট এবং আইপিএন লাইভ ইউআরএল কনফিগার না করা পর্যন্ত পেমেন্ট গেটওয়েকে "লাইভ রেডি" বলা নিষিদ্ধ।

3. **BLOCK-03: ৬০-সেকেন্ড এক্সপ্লেইনার ভিডিওর স্টুডিও ভয়েসওভার:**

   - তবে স্টুডিওতে প্রফেশনাল বাংলা ভয়েসওভার রেকর্ড করে অডিও ট্র্যাক সংযুক্ত না করা পর্যন্ত এটিকে "ন্যারেশন সহ ফুল অডিও ভিডিও" দাবি করা হবে না।

4. **BLOCK-04: গুগল ক্লাউড কনসোল ও-অথ (Google OAuth) রিডাইরেক্ট ইউআরআই সেটআপ:**

## ৭. ফাউন্ডারের জন্য গুগল ক্লাউড কনসোল সেটআপ গাইড (Google OAuth Setup)

গুগল লগইন লাইভ প্রোডাকশনে এক্টিভেট করতে ফাউন্ডারকে নিচের ৫টি সহজ ধাপ সম্পন্ন করতে হবে:

1. [Google Cloud Console Credentials](https://console.cloud.google.com/apis/credentials)-এ যান।
2. আপনার তৈরি করা **OAuth 2.0 Client ID (Web Application)** নির্বাচন করুন।
3. **Authorized JavaScript origins**-এ নিচের ৩টি ইউআরএল যোগ করুন:
   - `https://nihomi.com`
   - `http://localhost:3000`
   - `http://127.0.0.1:3000`
4. **Authorized redirect URIs**-এ নিচের হুবহু ইউআরএলটি যোগ করে **Save** বাটনে ক্লিক করুন:
   ```text
   https://aiychtkhktwsjrieeaha.supabase.co/auth/v1/callback
   ```
5. ক্লায়েন্ট আইডি ও ক্লায়েন্ট সিক্রেট কপি করে আপনার Supabase ড্যাশবোর্ডের `Authentication -> Providers -> Google`-এ পেস্ট করে 'Enable' করে দিন।
